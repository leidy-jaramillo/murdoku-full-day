# Murdoku · El caso AURA

Actividad de lógica para estudiantes y docentes durante el Full Day.

## Uso

Abre `dist/index.html` en un navegador actualizado. Funciona sin conexión; conserva la carpeta `dist/images` junto al HTML.

- Aprende a jugar: explicación y ejemplo guiado.
- El caso AURA: historia, perfiles de IA, pistas progresivas, cuadrículas y comprobación de respuestas.
- Modo proyección y explicación final protegida con clave del docente.

La actividad funciona en el navegador, sin cuentas ni servidor. La clave docente no se publica en estas instrucciones. El bloqueo de la explicación es una ayuda para la actividad, no un sistema de autenticación de usuarios.
